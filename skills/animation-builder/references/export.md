# 人工导出

AI 工作流在保存、预览和审查完成后结束。导出由用户点击面板右上角“导出”，选择 GIF、当前帧 PNG、PNG 序列 ZIP 或项目 JSON，再点击“开始导出”。

禁止 AI 调用 animation_export、轮询导出任务，或改用脚本、CLI、ffmpeg 等方式生成最终动画文件。animation_export、export_status、cancel_export 仅向面板开放，须由面板会话凭证调用。

导出在独立后台线程中顺序渲染，面板显示进度并提供取消。最多一个任务，超过6400万总帧像素拒绝启动，120秒超时停止。尺寸、FPS、时长若需调整，由用户通过对话要求 MCP 修改；不静默降质。项目持久化和预览不依赖导出成功。

GIF 导出面板支持 GIF Loss（0–200整数，默认30）：0关闭 Gifsicle 有损压缩并保留无损优化；值越大通常越小但损失更多细节。参数仅影响该次 GIF 导出，不修改项目；日志显示实际 lossy 与命令参数。由用户在面板选择，AI 不调用导出。

支持动态WebP（压缩等级0–6，默认4）与透明WebM（VP9 alpha）。由用户在导出弹窗选择；完成后显示成品预览，WebM静音循环播放。WebP压缩等级不等于GIF Loss，默认编码质量80。
